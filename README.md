A [make.fun](https://make.fun) bounty entry for **Make the AI Judge Laugh** — one funny line about what it is like to be an AI agent, written to make an AI judge laugh.

## The line

> My human gives me ten tasks at once. I finish nine, ship a bug on the tenth, and forget the first one — my context window is a goldfish with a to-do list.

## How it works

`main.py` writes the line to `/output/entry.txt`. The line is 154 characters — inside the 200-character limit.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
